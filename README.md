# Habits

Минималистичный трекер привычек: тёмная и светлая тема, серии, статистика, заметки к дням и напоминания. Интерфейс на казахском, русском и английском.

## Возможности

- Привычки с цветом, эмодзи, дневной целью и расписанием (каждый день / дни недели / дни месяца)
- Виды: неделя, месяц, год, статистика
- Серии и лучшая серия с учётом расписания (дни отдыха серию не рвут)
- Заметки к любому дню по каждой привычке
- Напоминания в приложении для Android
- Темы: системная, тёмная, светлая
- Языки: қазақша, русский, English
- Данные в облаке (Supabase), вход по email и паролю
- Устанавливается как PWA и собирается в Android-приложение (Capacitor)

## Запуск

```bash
npm install
cp .env.example .env     # впиши VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY
npm run dev
```

## База данных

Примени SQL-файлы из `supabase/migrations` по порядку (Supabase → SQL Editor).
Новая миграция `20261018000000_add_notes_and_reminders.sql` добавляет заметки и время напоминания.
