# Что изменено

## Исправлено
- Данные теперь общие для всех экранов (HabitsProvider): отметка на «Неделе» сразу видна в «Месяце», «Годе» и «Статистике»; новая привычка появляется сразу.
- Типы Habit, HabitCompletion, HabitWithCompletions, FrequencyType вынесены в `lib/supabase.ts`: `npm run typecheck` снова работает.
- Серия не обнуляется утром, пока сегодняшний день ещё не закончился.
- Лучшая серия учитывает расписание (раньше для «по дням недели» всегда была 1).
- Ошибка сохранения порядка привычек теперь обрабатывается.
- Отметки применяются мгновенно (оптимистично) и откатываются при ошибке сети.
- Удаление привычки: окно подтверждения вместо открытия редактора.

## Убрано
- Папка `.bolt`, бейдж Bolt в README, хук и CSS для скрытия бейджа, дефолтное имя пакета.
- Ключи Supabase можно задавать через `.env` (значения по умолчанию сохранены, чтобы деплой не сломался).

## Добавлено
- Светлая тема и выбор темы (системная / тёмная / светлая)
- Казахский язык (автоопределение языка при первом запуске)
- Заметки к дню по каждой привычке (меню карточки → «Заметка»)
- Напоминания по времени (в Android-приложении)
- Анимации: каскадное появление карточек, «поп» при отметке, пульс огонька серии, шторка заметок, виброотклик, уважение к настройке «уменьшить движение»
- Capacitor и инструкция публикации в Google Play (ANDROID.md)
