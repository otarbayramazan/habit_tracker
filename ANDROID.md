# Сборка Android-приложения и публикация в Google Play

## 0. Что понадобится
- Node.js 18+ и Android Studio (последняя версия)
- Аккаунт разработчика Google Play (разовый взнос $25)
- appId в `capacitor.config.ts` (сейчас `com.otarbayramazan.habits`). **После публикации менять нельзя.**

## 1. Подготовка
```bash
npm install
npx cap add android        # создаёт папку android/ (один раз)
npm run android            # сборка веба + sync + открыть Android Studio
```

## 2. Иконка и заставка
Положи в папку `assets/` файлы `icon-only.png` (1024×1024), `icon-foreground.png`, `icon-background.png` (1024×1024) и `splash.png` (2732×2732), затем:
```bash
npx capacitor-assets generate --android
```

## 3. Проверка на телефоне
Включи на телефоне «Режим разработчика» → «Отладка по USB», подключи и нажми Run в Android Studio.
Проверь: вход, отметку привычки, заметку, напоминание (включи в привычке время через 1–2 минуты).
На Android 13+ система спросит разрешение на уведомления, его нужно разрешить.

## 4. Подпись и релиз
1. Android Studio → Build → Generate Signed App Bundle → Android App Bundle (.aab)
2. Создай новый keystore. **Сохрани файл и пароли в надёжном месте: без них приложение не обновить.**
3. Не добавляй `*.keystore` и `*.jks` в git (уже в .gitignore).

## 5. Google Play Console
1. Создай приложение, заполни карточку: название, описание, скриншоты (минимум 2 телефонных), иконка 512×512, баннер 1024×500
2. Политика конфиденциальности (обязательна: приложение хранит email и данные привычек)
3. Раздел «Безопасность данных»: email, пользовательский контент (привычки, заметки), всё шифруется при передаче
4. Для новых личных аккаунтов Google требует закрытое тестирование: 12 тестировщиков в течение 14 дней перед выходом в продакшен
5. Загрузи .aab в закрытое тестирование → после периода подай заявку на продакшен

## 6. Обновления
Увеличивай `versionCode` и `versionName` в `android/app/build.gradle`, затем `npm run android` и новый .aab.

## Заметки
- Напоминания используют локальные уведомления и работают без интернета. После перезагрузки телефона Android восстанавливает их сам.
- На части телефонов (Xiaomi, Huawei, Samsung с агрессивной экономией батареи) уведомления могут приходить с задержкой: нужно разрешить приложению работать в фоне.
- Небольшая иконка уведомления по умолчанию берётся из иконки приложения. Для аккуратного вида можно добавить белый силуэт `ic_stat_icon.png` в `android/app/src/main/res/drawable*` и указать `smallIcon: 'ic_stat_icon'` в `capacitor.config.ts`.
